# 阶段五 M3 实现报告（经济与贸易）

> M3 目标：供需 → 价格 → 交易结算（阶段 9 填充）、配方驱动的生产（阶段 6 接入 WorkUnit）、能源与维护成本、玩家买卖（低买高卖）。

> **口径更正（2026-11-21）**：本报告原先表述为「M3 完成」，对照 `docs/phase5/batch-plan.md` 与游戏设计 §17 的验收标准，
> 实为**部分达成**：§17 要求的「前哨站→殖民地（等级）」「`Transfer` 抽象与守恒断言」「补给线」「D1 达成判定」
> **均未实现**；已实现的是配方生产、供需定价、财务（工资）与玩家交易。差距清单见 `batch-plan.md` §二。

## 一、验收结果

| 验收项 | 结果 | 证据 |
|---|---|---|
| **供需定价** | ✅ | 价格 = 基准价 × (目标库存/库存)^弹性，夹在 0.3×–5×；买卖价差 ±5% |
| **玩家交易** | ✅ | `trade buy/sell/quote`；货物在地点与船之间转移、信用点在玩家与地点之间转移，**总量守恒** |
| **部分成交** | ✅ | 库存/资金不足时按可用量成交并提示（实测卖出 76/150） |
| **价格随交易变动** | ✅ | 卖出 76 粮后，当地 food 买价 3.98 → 2.44 |
| **配方驱动生产** | ✅ | 冶炼：2 ore + 1 fuel → 1 alloy / 3 天；缺料停产 |
| **能源约束** | ✅ | fuel 作为配方输入，燃料耗尽即停工（10 燃料 → 约 10 炉后停） |
| **组织收支** | ✅ | 阶段 9 发工资（每人 1 信用点/天）；地点没钱则欠薪、士气下降 |
| **单元测试** | ✅ | fc-economy 11 个 + 既有 24 个，共 **35 个** 通过 |

## 二、新增内容

### 2.1 fc-config：资源与配方

| 类型 | 说明 |
|---|---|
| `ResourceDef` | 基准价、目标库存、价格弹性 |
| `RecipeDef` | 地点、工时、输入（含作为能源的 fuel）、输出 |
| `WorldDefinition.EconomyDef` | 资源表 + 配方表 + 玩家初始信用点 |

`world.xsd` 新增 `<resources>` / `<recipes>` / `playerCredits`；`default-world.xml` 定义 5 种资源、4 条配方、玩家 1000 信用点。

配方链：
```
ore + fuel --(3天)--> alloy        （熔炉殖民地 8）
fuel      --(2天)--> food          （农业站 15）
ore       --(3天)--> fuel          （天狼船坞 11）
food+alloy--(2天)--> supply        （Luna 站 3）
```
> 冶炼要燃料、农业要燃料——这就把"运燃料"变成必须做的事。

### 2.2 fc-sim：SPI 解耦

阶段 6/9 需要在 sim 里调用经济逻辑，但 `fc-economy` 依赖 `fc-sim`（不能反向）。因此定义 SPI：

| 接口 | 作用 |
|---|---|
| `spi.ProductionSystem` | `startUnits`（按配方扣输入开工）/ `onComplete`（发出产出） |
| `spi.MarketSystem` | `onTick`（工资结算、财务） |

`TickPipeline.m3(...)` 注入实现；`m2(...)` 退化为空实现（测试与 M2 兼容）。

`WorkStage` 改造：开工 → 推进（虚拟线程 + 固定顺序汇合）→ 完工结算 → 移除。

### 2.3 fc-economy

| 类 | 职责 |
|---|---|
| `PriceModel` | 幂函数定价 + 买卖价差 + 极端夹紧 |
| `Economy` | 资源/配方索引，按库存现算报价 |
| `ProductionSystemImpl` | 配方开工（扣输入）与完工（发产出 + 事件） |
| `MarketSystemImpl` | 工资结算与欠薪惩罚 |
| `TradeService` | 玩家买卖（部分成交、守恒） |

关键设计：**价格不落库**。价格由库存现算，存档只需存库存与信用点——这让存档与重放都更简单。

### 2.4 CLI

新增 `market [舰船]`、`trade buy|sell <资源> <数量> [舰船]`、`trade quote <资源>`；`status` 显示信用点。

## 三、运行示例

```
> market
---- Sol 索尔 行情（信用点 1000）----
  资源             库存       买入       卖出
  food          150     2.65     2.39
  fuel            0    15.75    14.25
  ore             0    15.75    14.25
  supply        200     2.81     2.55
  alloy           0    63.00    57.00

> trade buy food 150
买入 150 food @ 2.65，共 397.50；信用点余额 602.5

> sail 1 8
启航：晨星号 1 -> 8，预计 14 天，耗油 20
> next 14
时间推进 14 天，当前 SD 14（2200-01-15）；新增事件 1 条

> trade sell food 150
卖出 76 food @ 3.60，收入 273.60；信用点余额 876.1（请求 150，按可用量成交 76）

> market
---- Rigel Forge 熔炉殖民地 行情（信用点 876.1）----
  food          166     2.44     2.20      ← 卖多了，价格被打下来
```

自主生产（不操作也会发生）：
```
[SD 2]  生产完成 冶炼合金 → alloy+1
[SD 4]  生产完成 农业耕作 → food+4
[SD 6]  生产完成 冶炼合金 → alloy+1
...
（燃料耗尽后冶炼自动停产）
```

## 四、数值平衡（实测调整）

| 问题 | 处理 |
|---|---|
| 航线燃料成本远超货物利差 | 全部航线 cost 下调约 50%（如 10→5），fuel 基准价 4→3 |
| 零库存价格畸高（42/单位） | 价格夹紧区间从 0.2×~10× 收窄到 0.3×~5× |
| 卖货时买方没钱直接失败 | 改为**部分成交**并明确提示 |
| 开局多地欠薪 | 给 13 个地点配置初始信用点（150–500） |

## 五、守恒与边界

| 资源 | 守恒吗 | 说明 |
|---|---|---|
| 货物（food/fuel/ore/supply/alloy） | ✅ | 生产消耗输入、产出输出；交易只在库存间转移 |
| 信用点 | ✅（交易）/ ⚠️（工资） | 交易守恒；工资视为"生活消费离开被追踪经济体"，记账本扣减并在报告标注 |
| 价格 | 不落库 | 按库存现算，避免存档冗余 |
