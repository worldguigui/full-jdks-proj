## 三、结论与补齐清单

**M0/M1 真正完成；M2/M3 是「骨架+主要机制完成，验收条目未全达成」。**

要按 §17 真正关闭 M2/M3，需补：

**M2 补齐（3 项）**
1. `Faction` 实体 + 阶段 3 势力 AI（目标评估：现金流/领地/声望；与玩家无关地自主行动）；
2. 待决决策：重大事件生成选项，玩家在 CLI 里选择，结果进入编年史成为后续条件；
3. 离子风暴的下游链路：风暴 → 航线风险上升 → 航行延误/货损 → 产出下降 → 价格波动（至少 3 环可追溯），并给出「同一事件穿透多个系统」的查询命令；
4. 状态哈希工具：`TickPipeline` 每 N tick 输出状态 SHA-256，用于重放比对。

**M3 补齐（4 项）**
1. `Transfer` 抽象（地点→船→地点 的显式物流单据）+ 守恒断言（总量前后一致，失败即抛）；
2. 前哨站→殖民地等级（`Outpost` L0 → `Colony` L1…），升级消耗资源与时间；
3. 补给线：殖民地定期向附属设施调拨（或玩家设定自动补给路线）；
4. 首条贸易线登记 + D1 判定命令（`goals` 或 `milestones`）。
