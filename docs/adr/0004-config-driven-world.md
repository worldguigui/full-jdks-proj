# ADR-0004 配置驱动的世界

## 背景

地点、航线、舰船、主体、势力、资源与配方如果硬编码在世界装配代码中，会阻碍数据调整、Mod 与后续规模扩展，也会让测试依赖固定代码分支。

## 决策

- 世界数据全部来自 XML 配置，由 XSD 与语义校验装载为 `WorldDefinition`。
- `fc-config` 从 M0/M1 起就位，负责配置模型、校验与装载；存档、本地化与 Mod 配置合并属于后续模块。
- 装配器只实现规则，不硬编码具体地点、舰船、货物或配方。
- 配置错误在启动时失败并给出定位信息，不静默降级。

## 结果

- 默认世界与测试世界使用同一条装配路径。
- 新增地点、舰船、势力或配方只需修改配置，不改核心规则代码。
- 事件参数、技能成长等尚未配置化的内容记录为待决事项，而不是冒充已完成的配置化。
