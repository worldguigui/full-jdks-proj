# ADR-0002 确定性 Tick 管线与游戏时间

## 背景

回合制模拟需要可重放：同一种子与同一操作序列必须得到同一世界历史，才能用状态哈希做回归测试。异步事件、哈希表遍历序与共享随机流都会破坏这一性质。

## 决策

- 采用固定 12 阶段 Tick 管线，阶段顺序即依赖顺序。
- 1 tick = 1 星历日；`Stardate` 是状态、编年史与重放的唯一时间来源。系统时钟只用于日志。
- 独立子系统各自持有 `RngStreams` 派生流。
- tick 内事件进入有序 `EventQueue`，只在编年史阶段统一写入。
- `Flow`/事件总线只在 tick 结束后广播，不参与状态写入。
- 所有影响状态的遍历使用有序集合或显式排序。
- `StateHasher` 用 SHA-256 对确定性序列化结果求哈希，作为重放验收依据。

## 结果

- 同种子重放得到相同哈希；随机抽样与并发异步不会改变历史。
- 新增系统必须保持固定顺序、独立随机流与 tick 后通知的边界，否则视为架构回归。
