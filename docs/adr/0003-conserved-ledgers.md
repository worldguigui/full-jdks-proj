# ADR-0003 守恒账本与信用点分离

## 背景

经济系统需要可验证的守恒：运输不能凭空产生或丢失货物，余额不能用浮点数累积误差。信用点是货币而不是货物，混入库存会造成重复记账。

## 决策

- `ResourceLedger` 是货物的唯一权威账本；`Stock` 是地点分区的不可变快照，任何库存修改都经账本完成并同步视图。
- 货物共 11 种；数量使用 `BigDecimal`，库存不允许为负。
- 运输与补给线使用「在途分区」：发货时从来源分区移出并记入在途，抵达时从在途移入目标分区，总量在两端之间保持不变。
- 信用点只存在于 `MoneyLedger` 的账户中；账户之间转账，玩家支出不直接写库存。
- 生产是唯一增加货物总量的来源，消耗是唯一减少的来源；转运、交易与运输都断言总量不变。

## 结果

- 测试可以断言「交易/转移前后总量相等」「库存非负」「所有地点视图与账本一致」。
- 任何绕过账本直接修改库存的实现都被视为缺陷。
