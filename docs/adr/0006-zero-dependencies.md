# ADR-0006 零第三方依赖与自研测试框架

## 背景

项目目标是展示并真实使用 Java SE 21 标准 API。引入 JUnit、日志框架或 JSON 库会违反「零第三方编译/运行依赖」约束，也会把标准 API 的使用遮蔽掉。

## 决策

- 核心程序编译期与运行期不依赖第三方库；只使用 Java SE 21 正式 API，不使用 Preview/Incubator 特性。
- 测试使用自研 `fc-testkit`：`@FcTest` 注解 + 反射 runner，失败时进程退出码为 1。
- 每个有测试的模块在 Maven `test` 阶段用 `exec-maven-plugin` 启动独立的测试主类，显式传 `-ea`，保证断言生效、失败能中断构建。
- 构建工具与插件（Maven、编译器、打包插件）不属于运行时依赖。

## 结果

- `mvn dependency:tree` 中不存在第三方 compile/runtime 依赖。
- 测试可以完整覆盖装配、管线、守恒、确定性与 CLI 集成路径，且不依赖外部框架。
- 测试类显式进入各自的测试主类；不提供未实现的自动扫描入口。
