# ADR-0001 统一世界模型

## 背景

游戏同时包含星域航行与殖民地经营。若分别实现两套模拟器，会出现重复的状态、互不相通的库存与两套时间，世界历史也无法统一。

## 决策

用五个抽象覆盖两种尺度：

- `Location`：一切空间节点；`Ship` 是移动节点。
- `Link`：一切通行边。
- `Agent`：船员、居民、使者是同一类的三种角色。
- `Stock` + `ResourceLedger`：所有货物库存共用权威守恒账本。
- `WorkUnit` + `Recipe`：一切生产共用配方与工时。

只有一条 `Stardate` 时间轴与一部 `Chronicle`。sealed 根与全部 permitted 类型放在 `fc-world`；领域模块只提供行为与服务。

## 结果

- 星域与殖民地共享位置、库存、主体与事件模型，不存在并列的第二套世界状态。
- 新增尺度差异通过参数与子类型表达，而不是新增模拟器。
- 模块边界受 sealed 约束保护，跨模块新增 `Location`/`GameEvent` 子类型不被允许；扩展只能走 `non-sealed` 扩展口。
